# 提交操作清单

1. 把 `submission/my_submission.txt` 里的 `<...>` 替换成真实信息。
2. 确认 GitHub 仓库是 public，并 push 本目录。
3. Fork `OpenXiangShan/XiangShanLab`。
4. 在 `2026-CIE-RISC-V-Contest-Application-Track/` 下放 `my_submission.txt`。
5. 运行 `source ./submit.sh my_submission.txt`。
6. 确认生成 `01_参赛选手提交区/<team-name>/submission.asc`。
7. push 到自己的 Fork。
8. 向 `OpenXiangShan/XiangShanLab:main` 发 PR，标题：
   `[2026CIE大赛] vdot-team - 基于香山昆明湖V2的自定义vdot.vv指令`
9. 在官网系统上传 `docs/01–07` 的 PDF。
10. 按 `09_录屏脚本与演示指南.pdf` 录三段视频并上传。

> 详细步骤见提交包中的 `10_提交信息与操作指南.pdf` 或仓库 `docs/SUBMISSION.md`。
